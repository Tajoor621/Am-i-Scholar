Backup and data portability

Browser storage can be cleared. Save a backup outside this device regularly. Restoring a full web backup replaces this browser's current data after confirmation.

Android-format exports contain one paper, its notes and sources. The Android app's project-restore feature can import these exports. The web can also import Android-format backups as new projects.

Privacy and capabilities

No account, paid API, advertisements or remote data sync. Literature discovery in this web edition is a structured local source log, not a live database search. Citation output is a draft and must be checked against the target journal.
